# pnpm-monorepo

A modern monorepo managed with pnpm, supporting both applications and shared packages using TypeScript.

## Structure

- `apps/` — CLI and application projects
- `packages/` — Shared libraries and modules
- `docs/` — Project documentation

## Getting Started

1. Install dependencies:
   ```sh
   pnpm install
   ```
2. Build all packages:
   ```sh
   pnpm build
   ```
3. Run tests (if available):
   ```sh
   pnpm test
   ```

## Contributing

- All code is TypeScript-first
- Use `pnpm` for all package management
- See individual package and app folders for more details
