# Packages Folder

This folder contains all shared libraries and modules for the monorepo.

## Projects
- Each subfolder is a separate package/library.
- Example: `count-up` — a library for converting numbers to words.

## Development
- Each package is a TypeScript project with its own dependencies and build scripts.
- See the package's own README for usage and development instructions.
